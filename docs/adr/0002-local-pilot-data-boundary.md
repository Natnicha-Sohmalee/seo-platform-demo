# เก็บข้อมูล pilot ในเครื่องลูกค้า

ลูกค้าจริงหนึ่งธุรกิจจะติดตั้งและใช้เว็บ, worker และฐานข้อมูลบนเครื่อง Windows ผ่าน Linux ใน WSL และ Docker ข้อมูลธุรกิจและผลงานอยู่ในฐานข้อมูลบนเครื่องลูกค้า ส่วนการสร้างเนื้อหาใช้ AI API ออนไลน์ได้ โดยต้องแจ้งและได้รับความยินยอมก่อนส่งข้อมูลจริง รอบ pilot ใช้ข้อมูลทดลองและยอมรับการเริ่มใหม่ได้ จึงยังไม่ต้องมี backup; ก่อนใช้จริงใน production ต้องเพิ่มการสำรองและกู้คืนข้อมูลที่ทดสอบแล้ว
