# โปรเจกต์เป็นขอบเขตของงานเนื้อหา

ระหว่าง pilot ลูกค้าหนึ่งธุรกิจใช้หนึ่งบัญชี และงานอ่านเว็บไซต์ ชุดคีย์เวิร์ด แผนบทความ และบทความทั้งหมดอยู่ภายใต้โปรเจกต์ เว็บไซต์เป็นข้อมูลทางเลือก เพื่อให้ธุรกิจที่ไม่มีเว็บไซต์เริ่มงานได้และลูกค้าติดตามงานทุกชิ้นจากพื้นที่เดียวกัน โค้ดเดิมผูกผลอ่านเว็บไซต์กับโปรเจกต์ แต่เก็บงานเนื้อหาตามบัญชี; การย้ายงานเดิมต้องรักษาความสัมพันธ์และสิทธิ์เข้าถึงให้ถูกต้อง
